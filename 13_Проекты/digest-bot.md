# digest-bot

> Телеграм-бот, который каждые 6 часов просматривает подписанные каналы, через Claude API ранжирует посты и кидает самое интересное в приватный канал "Дайджест новостей". Плюс интерактивный поиск по темам.

- Claude API (ранжирование)
- APScheduler
